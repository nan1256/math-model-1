# 剩磁法雷击判定预测 —— 建模总结

## 1. 数据规模

- **样品总数**: 60个
- **样品类型**: 4种
  - 小号铁钉: 440条记录
  - 小号铁夹: 440条记录
  - 普通钢筋: 220条记录
  - 锈蚀钢筋: 220条记录
- **测量时间点(day>0)**: 22个
- **总数据点**: 1320条

## 2. 数据预处理说明

- 提取每个样品的初始剩磁值 M(0)
- 计算剩磁保持率 R(t) = M(t) / M(0)
- 计算衰减强度 Y(t) = -ln R(t)
- **移除 day=0 数据**：Y(0)=0 精确成立，保留 day=0 会人为引入截距偏差
- 合并天气数据（优先使用独立天气文件，否则回退到实验数据内置温湿度）

## 3. 特征变量构造

### 3.1 因变量

- $R_{i,s}(t) = M_{i,s}(t) / M_{i,s}(0)$
- $Y_{i,s}(t) = -\ln R_{i,s}(t)$（因变量，正值表示衰减）

### 3.2 环境变量标准化

- $z_T(d) = (T_d - \mu_T) / \sigma_T$
- $z_H(d) = (RH_d - \mu_H) / \sigma_H$

### 3.3 累计环境变量

- **$C_T(t) = \sum_{d=1}^{t} z_T(d)$** 累计温度暴露
- **$TOW(t) = \sum_{d=1}^{t} I_{wet}(d)$** 累计湿润时间，$I_{wet}=1$ 当 $RH>80\%$ 且 $T>0$
- **$C_{TH}(t) = \sum_{d=1}^{t} z_T(d) \times z_H(d)$** 温湿度耦合项

### 3.4 锈蚀损伤交互项

- $rust_0$ = 锈蚀等级（小号铁钉/铁夹=0, 普通钢筋=0, 锈蚀钢筋=3）
- **$rust\_TOW(t) = rust_0 \times TOW(t)$** 锈蚀-湿润交互项

### 3.5 磁黏滞对数时间项

- **$\log\_t = \ln(1 + t)$**

## 4. 模型公式

所有模型使用 $0 + C(\text{样品类型}):\text{测量天数}$ 交互项，避免截距引入的物理偏差。

### Model 1

$$Y = \alpha_s \cdot t + \varepsilon$$

### Model 2

$$Y = \alpha_s \cdot t + \beta_T C_T(t) + \beta_H TOW(t) + \varepsilon$$

### Model 3

$$Y = \alpha_s \cdot t + \beta_T C_T(t) + \beta_H TOW(t) + \beta_{TH} C_{TH}(t) + \varepsilon$$

### Model 4（稳健基准模型，不含 log_t）

$$Y = \alpha_s \cdot t + \beta_T C_T(t) + \beta_H TOW(t) + \beta_{TH} C_{TH}(t) + \beta_{rust} \, rust\_TOW(t) + \varepsilon$$

### Model 5（最终预测模型，含统一 log_t）

$$Y = \alpha_s \cdot t + \beta_{\log} \ln(1+t) + \beta_T C_T(t) + \beta_H TOW(t) + \beta_{TH} C_{TH}(t) + \beta_{rust} \, rust\_TOW(t) + \varepsilon$$

### Model 6（复杂对照模型，含 type 独立 log_t）

$$Y = \alpha_s \cdot t + \beta_{\log,s} \ln(1+t) + \beta_T C_T(t) + \beta_H TOW(t) + \beta_{TH} C_{TH}(t) + \beta_{rust} \, rust\_TOW(t) + \varepsilon$$

$\alpha_s$ 为第 $s$ 种样品类型的时间衰减斜率。

**模型角色**:

- Model 4：稳健基准模型（不含磁黏滞项），仅作对照
- Model 5：**最终预测模型**，加入统一 $\ln(1+t)$，Y/M空间误差均低于 Model 4
- Model 6：复杂增强模型（type独立 $\ln(1+t)$），参数多，仅作对照

**选择 Model 5 的理由**:

1. Y空间和M空间误差均优于Model 4
2. 参数增加有限（仅1个 log_t 系数），优于Model 6的4个独立系数
3. $\ln(1+t)$ 有明确的磁黏滞物理背景

## 5.5. 解释模型与预测模型的分工

### ExplainModel（解释模型）

$$Y = \alpha_s \cdot t + \beta_{\log} \ln(1+t) + \beta_{rust\_base} \cdot (Rust_0 \cdot t) + \varepsilon$$

**用途**：机理分析——回答时间是否主导、不同样品类型衰减斜率是否不同、锈蚀钢筋是否比普通钢筋衰减更快。仅包含时间、log_t 和锈蚀基线项，不含环境累计变量，避免共线性导致解释困难。

### Model 5（预测模型）

$$Y = \alpha_s \cdot t + \beta_{\log} \ln(1+t) + \beta_T C_T + \beta_H TOW + \beta_{TH} C_{TH} + \beta_{rust} \, rust\_TOW + \varepsilon$$

**用途**：工程应用——第23~29天剩磁预测、1~90天动态阈值、动态阈值置信区间、实际雷击判定流程。

**核心表述**：解释模型用于机理分析，预测模型用于工程应用。由于累计环境变量与时间变量存在共线性，本文不把 Model 5 中所有环境项解释为独立因果效应，而将其作为预测模型中的轨迹修正项。

详见 `explain_model_coefficients.xlsx` 和 `explain_vs_predict_model_comparison.xlsx`。

### 关键参数分析（注意：因变量为 $Y=-\ln R$）

- **正系数** → 增大 $Y$，表示增强衰减
- **负系数** → 减小 $Y$，表示对基础时间衰减趋势的补偿或修正

- **type:day 交互项（$\alpha_s$）**：各样品类型的基础时间衰减斜率。其中锈蚀钢筋的时间衰减斜率（约 0.0950）高于普通钢筋（约 0.0645），由于二者具有相同规格，差异主要来自锈蚀状态，说明锈蚀降低了剩磁稳定性并增强了基础时间衰减趋势。
- **log_t**：磁黏滞对数时间项，系数显著为正（约 0.281），说明加入前期弛豫效应后模型更能解释剩磁衰减。
- **C_T**：系数为正且显著（约 0.055），说明在控制其他变量后，累计温度暴露对衰减强度存在正向修正。
- **TOW、C_TH、rust_TOW**：系数为负且显著，应解释为共线性背景下的轨迹修正项，而非直接减缓或加速衰减的独立因果项。C_T、TOW、C_TH 与 day/log_t 均为时间累计或单调相关变量，存在较强共线性（VIF 最高达 197），因此其系数符号不宜直接解释为独立因果效应。
- **rust_TOW**：锈蚀-湿润交互修正项，系数为负（约 -0.0022）。在控制样品类型时间衰减斜率、log_t 与累计环境变量后，该项主要表示锈蚀样品在湿润暴露下相对于基础时间衰减趋势的补偿性修正，不单独解释为直接加速衰减。锈蚀影响主要通过锈蚀钢筋与普通钢筋的 type:day 斜率差异体现。

## 10. 动态阈值与单调修正

### 10.1 动态阈值公式

$$T_{dyn,s}(t) = T_{0,s} \times \exp[-\hat{Y}_s(t)]$$

其中 $T_{0,s}$ 为样品类型的静态阈值:

- 小号铁钉、小号铁夹: $T_0 = 1.0$ mT
- 普通钢筋、锈蚀钢筋: $T_0 = 1.5$ mT

### 10.2 单调性检查与修正

由于环境波动，原始预测的 $\hat{Y}(t)$ 可能局部下降，导致动态阈值局部上升，不符合剩磁单调衰减的物理规律。

**单调修正**:
$$Y_{mono}(t) = \max_{1 \le d \le t} \hat{Y}(d)$$
$$T_{dyn,mono}(t) = T_0 \times \exp[-Y_{mono}(t)]$$

原始阈值反映环境波动，单调修正版更适合实际判定流程。

详见 `dynamic_threshold_monotonic_check.xlsx` 和 `monotonic_dynamic_threshold_1_90.xlsx`。

### 10.3 动态阈值置信区间

基于 Model 5 残差标准差 $\sigma_Y$ 构造近似 95% 阈值区间：

$$Y_{lower} = \hat{Y} - 1.96\sigma_Y, \quad Y_{upper} = \hat{Y} + 1.96\sigma_Y$$
$$T_{upper} = T_0 e^{-Y_{lower}}, \quad T_{mean} = T_0 e^{-\hat{Y}}, \quad T_{lower} = T_0 e^{-Y_{upper}}$$

动态阈值区间可用于雷击判定置信度分级。

详见 `dynamic_threshold_with_interval_1_90.xlsx`。

### 10.4 雷击判定分级规则

| 条件                                   | 判定         | 说明                       |
| -------------------------------------- | ------------ | -------------------------- |
| $M_{obs} \ge T_{upper\_95}$            | 高置信雷击   | 实测剩磁高于阈值上界       |
| $T_{mean} \le M_{obs} < T_{upper\_95}$ | 疑似雷击     | 实测剩磁处于均值与上界之间 |
| $T_{lower\_95} \le M_{obs} < T_{mean}$ | 低置信疑似   | 需结合现场证据综合判断     |
| $M_{obs} < T_{lower\_95}$              | 雷击证据不足 | 实测剩磁低于阈值下界       |

详见 `lightning_decision_workflow.xlsx`。

## 12. 结论（可直接用于论文）

1. **时间延迟是剩磁衰减的主导因素**。Model 5 中四类样品的 type:day 时间衰减斜率均显著为正，说明剩磁保持率随检测延迟时间增加而持续下降。

2. **样品类型差异显著**。四类样品的时间衰减斜率不同，说明尺寸、形状和材料状态会影响剩磁稳定性。

3. **锈蚀状态降低剩磁稳定性**。普通钢筋与锈蚀钢筋规格相同，但锈蚀钢筋的时间衰减斜率（约 0.0950）高于普通钢筋（约 0.0645），说明锈蚀状态会增强基础时间衰减趋势。

4. **环境累计变量对衰减轨迹具有显著修正作用**。C_T、TOW、C_TH 等变量在模型中具有统计显著性，但由于它们与 day/log_t 存在较强共线性（VIF 最高达 197），其系数不宜解释为严格独立因果效应。

5. **rust_TOW 是锈蚀-湿润交互修正项**。由于其系数为负，该项主要表示锈蚀样品在湿润暴露下相对于基础时间趋势的补偿性修正，不单独解释为直接加速衰减。

6. **加入 log_t 后预测能力显著增强**。与 Model 4 相比，Model 5 在训练集误差和 Leave-One-Day-Out CV 中均取得更低的 RMSE，说明磁黏滞对数时间项能够有效提升未观测时间点预测能力。

7. **动态阈值修正适用于灾害上报滞后的雷击鉴定场景**。基于 Model 5 的动态阈值能够根据检测延迟和环境暴露修正静态阈值，单调修正版则更适合实际判定流程。

8. **Leave-One-Day-Out CV 验证了模型对未观测时间点的预测能力**，Model 5 的 CV_RMSE_M=0.090 mT，显著优于 Model 4 的 0.187 mT。

9. **Leave-One-Sample-Out CV 验证了模型对新样品的泛化能力**，说明模型不依赖于特定样品训练集。

10. **动态阈值区间比单点阈值更适合实际鉴定**：基于 95% 置信区间的分级规则可提供置信度分级，避免单点阈值在高不确定性场景下的误判。

11. **解释模型用于机理分析，预测模型用于动态阈值和工程应用**。解释模型仅含时间、log_t 和锈蚀基线项，便于解释；预测模型含环境累计变量，作为轨迹修正项提升预测精度。
12. **环境变量因共线性不作强因果解释**，而作为预测模型中的轨迹修正项。
